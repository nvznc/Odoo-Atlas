Versión C# para Windows
------------------------

En `jposbox-cs/` hay una recreación completa en **C# / WinForms** que se compila a un
único `jPosBox.exe` usando .NET Framework 4.8 (incluido en Windows, sin instalar nada).
Incluye servidor HTTP propio para los endpoints `hw_proxy`, impresión nativa en
cualquier impresora de Windows, configuración INI, log y utilidades para generar
vistas previas PNG o PDF. Instrucciones: [`jposbox-cs/README.md`](jposbox-cs/README.md).
